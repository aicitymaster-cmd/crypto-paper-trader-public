# 仮想通貨 PAPER 7日間検証

AI CITY本体とは分離した、実資金を使わない公開検証用リポジトリです。

## 現在の検証
- 対象: BTC / ETH / SOL / XRP / DOGE
- データ: bitbank 公開APIの5分足・ティッカー
- 戦略: モメンタム / ブレイクアウト / 平均回帰
- 各戦略の開始仮想資金: 10,000円
- 実現利益の50%を仮想的に取り分け
- 売買コスト: 実際のbid/askに加え、仮想手数料0.15%/片道と追加スリッページ0.05%を保守的に計上
- 実口座、APIキー、実注文、送金、出金、レバレッジ、先物、空売り: なし
- 7日終了後は状態を終了扱いにし、自動で新しい検証を開始しません

## セキュリティ
- GitHub Actions: `permissions: {}`
- Secrets不使用
- 外部PRをトリガーにしない
- GitHub-owned `actions/cache` だけを固定SHAで使用
- 公開情報へのHTTPS GET以外の取引所通信なし
- 状態キャッシュが途中で消えた場合、初期化し直さず停止

ローカル公開候補の確認:
- `python security_guard.py .` -> `SECURITY_GUARD_OK`
- `python -m unittest discover -q` -> 242 tests, OK

これは「勝てること」を証明するものではありません。7日間の実市場PAPERデータで、戦略の勝率、損益、取引回数、コスト影響などを確認するための検証です。
